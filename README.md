Vehicle Rental Fleet Management System

This is a lightweight web application designed to manage a vehicle rental fleet, track registered customers, and handle active rental bookings. The backend is built using PHP with database queries, and the frontend uses CSS and JavaScript for the layout and dashboard metrics.

Main Features:
- Operational Dashboard: Displays total fleet, registered clients, and active bookings.
- Fleet Management: Handles vehicle tracking and status updates via vehicles.php.
- Customer Records: Manages client data via customers.php.
- Bookings Center: Manages ongoing vehicle rentals via rentals.php.

Tech Stack Breakdown:
- Server-side: PHP 
- Styling and Layout: CSS
- Client-side Scripting: JavaScript
